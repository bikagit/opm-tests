# SPE11 Deck Overview

Narrative summary of the decks in this directory. For the full catalogue with links to every DATA file and TOML config, see [README.md](README.md).

---

## Directory structure

| Directory | Purpose |
|---|---|
| `SPE11A/`, `SPE11B/`, `SPE11C/` | Official baseline decks — the primary decks for solver comparison runs |
| `SPE11C_350k/` | SPE11C variant with 350,000-day (1000 yr) simulation instead of 730,000 |
| `benchmark/` | Full-resolution benchmark decks (r1–r5), organised by case |
| `convergence/` | Grid convergence study decks at multiple resolutions |
| `derived/` | Physics variants (e.g. no dispersion) |
| `examples/` | Small quick-run decks for smoke-testing |
| `tests/` | Minimal test cases (Cartesian, corner-point, data-format variants) |
| `pyopmspe11/` | The pyopmspe11 generator code plus its own test/benchmark decks |
| `configs/` | TOML config files used to generate the decks |

All decks are generated by [pyopmspe11](https://github.com/OPM/pyopmspe11).

## Official baseline decks

These are the top-level decks used as the default input for solver comparison runs.

| Deck | Grid | Cells | Physics | Sim time |
|---|---|---|---|---|
| `SPE11A/SPE11A.DATA` | Cartesian 280×1×120 | 33,600 | Isothermal | 5 days |
| `SPE11B/SPE11B.DATA` | Cartesian 842×1×120 | 101,040 | Thermal | 730,000 days (~2000 yr) |
| `SPE11C/SPE11C.DATA` | Corner-point 170×102×120 | 2,080,800 | Thermal | 730,000 days (~2000 yr) |

SPE11A is a 2D (NY=1) isothermal CO2 injection and falloff test over 5 days. SPE11B adds thermal physics and extends to 2000 years. SPE11C adds the third spatial dimension.

`SPE11A/SPE11A.DATA` corresponds to benchmark variant **r2** (Cartesian 1 cm with capillary pressure max 2500 Pa). `SPE11B/SPE11B.DATA` corresponds to **r1** (Cartesian 10 m). `SPE11C/SPE11C.DATA` corresponds to **r1** (Cartesian 50 m × 50 m × 10 m).

## SPE11A benchmark variants (r1–r5)

| Variant | Directory | Grid type | Cells | Key difference |
|---|---|---|---|---|
| r1 | `benchmark/spe11a/r1_Cart_1cm/` | Cartesian | 33,600 | Base 1 cm grid, no capillary pressure max |
| r2 | `benchmark/spe11a/r2_Cart_1cm_capmax2500Pa/` | Cartesian | 33,600 | Adds capillary pressure max 2500 Pa |
| r3 | `benchmark/spe11a/r3_cp_1cmish_capmax2500Pa/` | **Corner-point** | 51,240 | Corner-point grid (183 layers), capmax 2500 Pa |
| r4 | `benchmark/spe11a/r4_Cart_1mm_capmax2500Pa/` | Cartesian | 3,360,000 | 10× finer resolution (1 mm cells) |
| r5 | `benchmark/spe11a/r5_Cart_1mm_capmax2500Pa_strictol/` | Cartesian | 3,360,000 | r4 with strict solver tolerances |

The same decks exist under `pyopmspe11/tests/decks/spe11a/` — these are identical files generated by the same tool and used for generator regression testing.

**r3 is the recommended deck for solver robustness testing** because the corner-point grid is harder to solve than the equivalent Cartesian grid at the same resolution:
- The geometry introduces off-diagonal Jacobian coupling that stresses the CPR pressure extraction
- All TSTEP blocks: 5×0.02083 days + 5×0.02083 days + 115×0.04167 days = 5.0 days total
- Fixed CPR configs (all 24 sweep labels) fail at day 0.209 — the first step of the third TSTEP block — where the timestep doubles and the second CO2 injector is shut off simultaneously

### TSTEP structure (r3 corner-point)

```
Block 1:  5 × 0.020833 days  →  day 0.000 – 0.104   (first injector only)
Block 2:  5 × 0.020833 days  →  day 0.104 – 0.208   (both injectors)
Block 3: 115 × 0.041667 days →  day 0.208 – 5.000   (second injector off; step size doubles)
```

The failure of fixed CPR configs at day 0.209 is caused by the simultaneous source-term change and timestep doubling at the boundary between blocks 2 and 3. Neural CPR survives this by dynamically selecting different preconditioner configs per Newton step.

## Convergence study decks

Two series of SPE11B-geometry decks for grid convergence analysis, all running 500 years (182,500 days):

**Full domain** (`convergence/full_cpN-*`): 4 resolutions from 40 m (5,300 cells) down to 5 m (377k cells).

**Lower domain only** (`convergence/lower_cpN-*`): 6 resolutions from 160 m (162 cells) down to 5 m (123k cells). The coarsest (320 m) failed to generate due to a degenerate grid.
